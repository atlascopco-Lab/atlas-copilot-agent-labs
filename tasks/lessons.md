# Lessons

## 2026-10-16 · 教学设计要从学员视角写
- 错误：第一版教学设计只写「学员做什么步骤」，没讲清学的是 Copilot 哪些功能、每一步对项目意味着什么。
- 规则：培训材料每个环节都要回答三问——用了什么功能 / 它替我做了什么 / 对项目意味着什么；开场给功能地图和项目地图；
  有 vibe coding 热身；gh-aw 这类功能要讲清机制（触发、白名单、safe-outputs、编译）而不是只演示。

## 2026-10-17 · 在浏览器里操作 Codespace / Studio 的三个坑
- 错误 1：终端里跑 `code -g 文件` 后焦点跳到编辑器，紧接着「在终端里打字」其实写进了文件。
  规则：每次要在终端输入前，先点一下终端（或用命令面板 Terminal: Focus Terminal），并用截图确认光标在终端。
- 错误 2：经终端给代码打补丁时，shell → python 的多层转义把 `\n` 变成真换行，改坏了 api.ts。
  规则：先备份；补丁脚本在本机写好、dry-run，再用 base64 传进去执行；改完立刻跑语法检查（node --check / typecheck），调试代码用完马上恢复并 `git diff` 确认无残留。
- 错误 3：Copilot Studio 指令编辑器会随滚动重排，按截图坐标点击会把字插到段落中间。
  规则：点击后先放大截图确认光标位置再输入；没保存前发现错位就 Cancel → Discard。
